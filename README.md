# 🌙 LUNARO — LNR

**LUNARO (LNR)** is a Telegram-based Web3 ecosystem built on the **TON Mainnet**.

LUNARO provides a Telegram Mini App where users can connect a TON-compatible wallet, mine LNR, claim rewards, hold LNR and participate in the growing LUNARO ecosystem.

---

## 🚀 About LUNARO

LUNARO is designed to make participation in the TON ecosystem simple and accessible directly through Telegram.

The LUNARO Mini App combines:

- ⛏️ LNR Mining
- 👛 TON Wallet Connection
- 💎 LNR Claim System
- 🤝 Referral System
- 💸 Automated Withdrawals
- 📱 Telegram Mini App
- 🌐 TON Mainnet integration

The project is actively being developed and its ecosystem will continue to expand over time.

## ⛏️ LNR Mining

LUNARO uses a Telegram Mini App mining system.

Users connect a compatible TON wallet before accessing the mining system.

Mining rewards accumulate separately as **unclaimed LNR**.

Unclaimed mining rewards are not automatically counted as the user's claimed wallet balance. Users must use the Claim system according to the rules of the LUNARO application.

This distinction helps separate:

**Mined / Unclaimed LNR**

from

**Claimed / Wallet LNR**

---

## 💎 Claim System

The Claim system allows users to claim accumulated mining rewards.

After claiming, the corresponding LNR becomes part of the user's claimable balance according to the LUNARO system rules.

LUNARO is designed to maintain a clear distinction between rewards accumulated inside the Mini App and LNR held in a user's personal wallet.

---

## 👛 Wallet & Total Assets

LUNARO distinguishes between application balances and personal wallet holdings.

### Holding Wallet

The **Holding Wallet** represents the user's connected personal TON wallet where LNR can be held.

### Total Assets

**Total Assets** represents the user's overall LNR asset position according to the LUNARO application logic, including relevant application balances and connected-wallet holdings.

## 🤝 Referral System

Referral rewards are calculated according to the official LUNARO referral rules and qualifying claimed activity.

## 📊 Transparency

LUNARO aims to provide clear and verifiable information about its ecosystem.

As the project develops, public documentation may include:

- Total Mini App users
- On-chain holder count
- Claimed LNR
- Unclaimed LNR within the Mini App
- Token allocation
- Contract information
- Blockchain activity
- Project updates

It is important to distinguish between **users of the Mini App** and **on-chain token holders**.

LNR earned through mining may remain unclaimed inside the Mini App. Such balances do not represent personal on-chain wallet holdings until the corresponding tokens are claimed and transferred according to the LUNARO system.

The **User Balances — Unwithdrawn** allocation represents LNR already assigned to users but not yet withdrawn. These balances are reserved for eligible users and are part of the existing total supply.
